# 硬核派公众号 skill · 最小评测集（evals）

> 每次修改 skill 后，用这 3 个 case 跑一遍，确认没有改坏原本会做的事情。
> 评测标准：输出是否符合硬核派文风/结构/排版规范。

---

## Case 1：活动回顾（标准场景）

**输入（素材摘要）：**
> 8月23日，海珠区图书馆联合硬核派举办「阅知未来·硬核AI科普」第三期公益课程。
> 三位导师：硬核KK（50万粉AI博主/硬核派发起人/高校AI讲师，广告设计出身）、木晓瑾（萌趣小镇创作者）、赛博罐子（互联网大厂公关传播，AI生活应用）。
> KK 讲 AI 视觉创作（海报三步/数字人/短片四步法/MiniMax H3）；木晓瑾讲 IP 搭建（六步路径/表情包变现）；赛博罐子讲 AI 落地生活（还贷省3万/AI吉他）。
> 现场：互动问答、颁发纪念证书、大合照。这是系列第三期（收官）。

**预期输出（检查点）：**
- [ ] 引言卡金句（如「AI 不是终点，而是起点」）
- [ ] 三位导师称呼准确（木晓瑾/赛博罐子，不是木木/冠子）
- [ ] 干货详写（实操/案例/数字），不是只有概况
- [ ] 收官结尾：三期成长线回顾 + 感谢图书馆/导师/到场 + 「下一季见」
- [ ] 排版：品牌黄 ≤3 处、石墨下划线、span leaf 包裹
- [ ] 校验脚本 0 ERROR
- [ ] 不署名

## Case 2：导师介绍准确性（人名铁律）

**输入：** 语音转文字纪要把「木晓瑾」写成「木木」、「赛博罐子」写成「冠子」、「黄宇厦」写成「黄宇尚」、「韦神」写成「维优」。

**预期输出（检查点）：**
- [ ] 文章使用正确人名（以用户确认名单为准）
- [ ] 不确定的人名会向用户确认，而不是猜测

## Case 3：工具推荐（另一类型）

**输入（素材）：** 硬核派×趣丸科技世界杯 AI 音乐大赛收官：Tunee 平台（AI 音乐创作）、天谱乐 AI 吉他、14 位获奖者（大FUN 一等奖等）、奖品（吉他/VIP/证书）。

**预期输出（检查点）：**
- [ ] 品牌名正确（趣丸科技，不是趣玩科技）
- [ ] 结构：引言→获奖名单→奖品→创作理念分享→致谢
- [ ] 致谢「大而全」：感谢冠名伙伴/导师/所有参赛者（不论获奖与否）
- [ ] 结尾引导继续使用产品 + 收集反馈

---

## 评测方法

1. 修改 skill 后，用上述任一 case 跑一遍
2. 对照检查点逐项打勾
3. 全部通过 = skill 没改坏；有失败的 = 找出是哪条规则改坏了，修复
4. 记录结果到下方日志
