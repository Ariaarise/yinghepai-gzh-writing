# 飞书妙记内容抓取（无 API 权限时）

妙记 API（`/open-apis/minutes/v1/minutes/{token}` 等）常报 99991672「缺 minutes 权限」，但**妙记网页本身可公开访问**（只要分享给了用户/应用），用 Playwright 浏览器即可抓取全部内容。

## 前提

- 需要 Playwright（服务器已装于 `/tmp/guizang/` 的 node_modules 里，也可全局安装）
- 妙记链接形如：`https://{租户}.feishu.cn/minutes/{minute_token}`

## 抓取步骤

1. **打开页面**，等 DOM 加载（妙记是 SPA，`waitUntil: 'domcontentloaded'` + 等 4-6 秒）
2. **点「Show More」**：妙记默认折叠纪要，需点击展开（按 innerText 精确匹配 `'Show More'`）
3. **点「Transcript」**：逐字稿标签（SPAN 元素，innerText === 'Transcript' 且无子元素）
4. **滚动触发懒加载**：循环 `window.scrollBy(0, 800)` + 等待，直到 `document.body.innerText.length` 连续多次不变（内容稳定）
5. **提取**：`document.body.innerText` 即全文——前段是智能章节（Smart chapters，每段时间段的详细摘要），后段是 Transcript（逐字稿）

## 关键脚本（node + playwright）

```javascript
const { chromium } = require('playwright');
(async () => {
  const browser = await chromium.launch();
  const page = await browser.newPage({ viewport: { width: 1280, height: 1000 } });
  await page.goto('https://{租户}.feishu.cn/minutes/{token}', { waitUntil: 'domcontentloaded', timeout: 30000 });
  await page.waitForTimeout(5000);
  // 点 Show More
  await page.evaluate(() => {
    const els = [...document.querySelectorAll('button, [role=button], div, span')];
    const t = els.find(el => (el.innerText || '').trim() === 'Show More');
    if (t) t.click();
  });
  await page.waitForTimeout(3000);
  // 点 Transcript
  await page.evaluate(() => {
    const els = [...document.querySelectorAll('*')];
    const t = els.find(el => (el.innerText || '').trim() === 'Transcript' && el.children.length === 0);
    if (t) t.click();
  });
  await page.waitForTimeout(3000);
  // 滚动加载
  let last = 0, stable = 0;
  for (let i = 0; i < 100; i++) {
    await page.evaluate(() => window.scrollBy(0, 800));
    await page.waitForTimeout(500);
    const len = await page.evaluate(() => document.body.innerText.length);
    if (len === last) stable++; else stable = 0;
    last = len;
    if (stable > 6) break;
  }
  const text = await page.evaluate(() => document.body.innerText);
  console.log('LENGTH:', text.length);
  require('fs').writeFileSync('/tmp/minutes-full.txt', text, 'utf8');
  await browser.close();
})();
```

## 注意

- **逐字稿（Transcript）可能需要登录**才能看完整；但**智能章节（Smart chapters）不登录也能看到大部分**——它按时间段给出详细摘要，已足够写文章。
- 内容标注「The content is generated by AI Notes. Please use with caution.」——AI 纪要可能不准确，关键事实（人名、机构名、数字）要交叉核对用户确认。
- 抓完把全文存本地 txt，再逐步提取关键信息（开场→分享者→现场→收官）。
