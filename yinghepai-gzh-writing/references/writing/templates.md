# 文章类型模板（templates）

> 每种文章类型的结构骨架。完整真实范本见 `references/activity-review-template.md`（三期已发布文章）。

## 类型 A：活动回顾（最常见）

```
QUOTE 引言卡（金句，从活动里最有张力的一句话提炼）
前言（活动时间地点+主题+一句话概述）
01 分享者/环节（每人或每环节一小节，详写核心内容）
02 现场互动/问答（有趣的问答、现场反应）
03 颁奖/特殊环节
∞ 结语（升华主题 + 感谢主办方/嘉宾 + 引导关注）
END 线（不署名）
```

## 类型 B：工具/内容推荐

```
引言卡（痛点或钩子）
01-04 每个工具：适合什么 / 内容 / 特征
结尾：引导互动（「你最想拿哪个试试？评论区告诉我」）
```

## 类型 C：人物专访/特稿

```
引言卡（被访者金句）
01 认识 TA（背景介绍）
02 成长线/经历脉络
03 方法/干货
04 快问快答
∞ 结语
```

## 类型 D：赛事公告

```
标题（活动名 + 动作 + 时间节点）
主题/背景
规则（清晰呈现）
奖项
参与方式/时间节点
报名引导
```

## 类型 E：合作宣传

```
标题（品牌 + 事件 + 核心利益）
合作背景
活动内容
致谢合作方
引导关注
```

## 标题策略（按类型，不是全局一刀切）

| 文章类型 | 标题策略 | 示例 |
|---------|---------|------|
| 活动回顾 | 现场感/结果/冲突/数字 | 椅子全搬空！这场广州 AI 公益课凭啥吸引100+人到场？|
| 工具推荐 | 痛点/结果/使用场景 | 免费学到省下3万块的AI实操？|
| 人物专访 | 人物身份/反差/核心观点 | 律师、导演、设计师都在用千问做产品 |
| 赛事公告 | 活动名/动作/时间节点 | 硬核派×趣丸科技｜世界杯AI音乐大赛收官 |
| 合作宣传 | 品牌+事件+核心利益 | 千问×硬核派体验会：六个用AI做出来的项目 |

通用底线：≤20字（公告可稍长）、去专业术语、不锁死数量、不夸大。
